
# C++ Calculator

A command-line calculator developed using C++.
This project demonstrates basic arithmetic operations,
functions, header files, and multi-file program organization.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Division-by-zero handling

## Technologies Used

- C++
- Standard C++ Library
- Git and GitHub

## Requirements

- A C++ compiler (GCC or MSVC)
- C++11 or later
- Git (for cloning the repository)

## Project Structure

```text
Calculator/
├── main.cpp
├── Calculator.cpp
├── Calculator.h
└── README.md
```

## Installation

Clone this repository:

```bash
git clone https://github.com/USERNAME/Calculator.git
```

Navigate to the project directory:

```bash
cd Calculator
```

## Compilation

Using g++:

```bash
g++ main.cpp Calculator.cpp -o calculator
```

## Execution

On Windows PowerShell:

```powershell
.\calculator.exe
```

On Linux or macOS:

```bash
./calculator
```

## Usage

1. Run the calculator.
2. Select an arithmetic operation.
3. Enter the required numbers.
4. View the result.
